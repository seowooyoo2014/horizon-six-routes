# 수평선의 장부: 플레이 가능한 프롤로그

1990년대 항해 RPG의 선택형 주인공, 항구 경제, 바람 항해, 사건 해금 구조를 독립 IP로 재구성한 Unity 2D 프로젝트입니다.

## 캐릭터 그림 교체

캐릭터 애니메이션은 [스프라이트 편집기](Tools/sprite_editor.html)에서 마을 PNG와 실내 PNG를 따로 자를 수 있습니다. 자세한 순서는 [편집기 안내](Tools/SPRITE_EDITOR_GUIDE.md)를 참고하십시오. 내보낸 PNG 두 장과 JSON 한 장은 게임 설정의 `사용자 스프라이트`에서 함께 적용합니다.

## 실행

1. Unity Hub에서 이 폴더를 Unity `2022.3.51f1`로 엽니다.
2. 첫 가져오기가 끝나면 `Assets/Scenes/Boot.unity`가 자동 생성되고 열립니다.
3. 상단의 Play 버튼을 누릅니다.

Unity가 아직 설치되지 않았다면 Unity Hub에서 `2022.3 LTS`를 설치하면 됩니다. 프로젝트의 기준 화면은 16:9이며 에디터 Game 뷰는 `1280×720`을 권장합니다.

## 프롤로그 흐름

- 타이틀과 자동 저장 이어하기
- 네 선장 선택 화면과 리안 팔코 프롤로그
- 벨라 항에서 보급품과 유리 공예품 적재
- 풍향, 돛 단계, 사행을 이용한 측면 항해
- 표류 상선 구조 분기
- 제노아 남항의 교역과 서점 사건
- 왕립 추적선 탈출과 프롤로그 완료

## 조작

- 메뉴: 방향키 또는 게임패드 스틱, `Enter`/게임패드 A 선택
- 항해: `W/S` 또는 위/아래로 돛 단계 조절
- 항해: `A/D` 또는 좌/우로 사행 방향 조절
- `F5`: 기록 1에 빠른 저장
- `Esc`: 타이틀로 돌아가기

## 주요 위치

- `Assets/Scripts`: 게임 상태, 교역, 저장, 화면, 항해 구현
- `Assets/Resources/Data/Prologue`: 항구, 상품, 임무, 사건 데이터
- `Assets/Resources/Sprites/Game`: 오리지널 픽셀풍 게임 자산
- `Assets/Resources/Audio`: 장면별 오리지널 음악과 효과음
- `Assets/Tests/EditMode`: 데이터, 교역, 저장 직렬화 테스트
- `Docs/reverse_design.html`: 조사 기반 역기획서

자동 저장은 출항, 입항, 사건 완료, 항해 중 보급 소비 시 갱신됩니다. 수동 저장 슬롯은 3개이며 저장 파일은 Unity의 플랫폼별 영구 데이터 폴더에 보관됩니다.
