# 수평선의 여섯 항로 V16

## 시작 순서

1. 항해 파일 1~3 중 하나를 고른다.
2. `새 항해`를 선택한다.
3. 여섯 선장의 능력치, 시작항, 자금, 기함과 특기를 비교한다.
4. 선장을 확정하면 짧은 프롤로그 뒤 시작항에서 조작을 시작한다.

## 여섯 캠페인

- 케말 빈 유수프: 실종된 동생과 채무 선원을 찾는 구조·잠입 항해
- 이네스 데 알라르콘: 압수된 측량 기록을 되찾아 세계지도를 완성하는 탐험 항해
- 두아르트 드 아벨라르: 전설로 왜곡된 동방 국가의 실제 역사를 확인하는 외교 원정
- 마테오 다 코르바라: 위조 채무와 난파선 유물의 출처를 밝히는 인양 모험
- 앤 펜윅: 거짓 사략 명령을 추적하고 독립 구조 함대를 만드는 전투 항해
- 마리커 판 데르 펠데: 10금으로 시작해 공동 보험과 곡물망을 세우는 교역 항해

각 캠페인은 6장, 18개 핵심 목표, 18개 이야기 장면, 4개 중요 선택으로 구성된다. 다른 다섯 선장은 필수 임무와 별개의 항구 조우로 등장한다.

## 조작

- 이동: 방향키 또는 WASD
- 조사·결정: Enter, Z 또는 Space
- 취소·항해 일지: Esc 또는 X
- 세계지도: M
- 게임패드: 방향 패드, A 확인, B 취소, Select 세계지도

항해 일지에는 지금 할 일, 목적 항구와 시설, 예상 항해일, 권장 식량·물과 위험도가 표시된다.

## 저장 호환

- V16 저장은 `horizon-ledger-v16-slot-*` 키를 사용한다.
- V15 저장은 삭제하거나 덮어쓰지 않고 V16 슬롯으로 복사한다.
- 기존 리안 저장은 `리안의 항해 기록`으로 표시되며 기존 캠페인을 계속 진행할 수 있다.
